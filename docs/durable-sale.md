# 家電・車などの売却と端数調整

メイン画面の全分類で、登録済み商品の編集フォームに売却操作を表示します。位置は「追加費用」の下、「合計・月額コスト」の上です。既存の登録・更新・一覧に戻るボタンは移動しません。

- 売却価格は手数料・送料を引いた手取り額です。「決定」はフォーム内の確定で、「更新する」で保存します。売却内容の変更・記録の削除も更新して保存します。
- 購入価格と追加費用の合計を計算対象にします。売却前の計上済み費用と売却手取りを引いた残額を、残りの家計簿の計上回数に配分します。PCと同じ計算エンジンを使用し、休日調整を含む実際の締め日を基準にします。
- 新規登録の通常月額は切り捨てます。既存データは従来の四捨五入の月額を維持します。購入総額との差額は最終期間で調整し、売却時には未計上の端数を売却後の残額へ引き継ぎます。元の最終調整が済んだ後の売却は、調整分を重複計上しません。
- 全期間の費用合計は、購入価格＋追加費用−売却手取りです。使用予定期間を過ぎてからの売却は指定回数（初期値12回）で配分します。
- 調整分は通常月額・売却後月額の右に表示します。負の月額は計算結果と集計に含め、帯には表示しません。PCの帯も同様です。
- 非表示・集計から除外の設定を維持します。売却記録を削除すると、売却が設定した使用終了日だけを元に戻します。
- 「PC管理を反映」する集計用商品では、売却は個別のPCパーツ側で登録します。集計用商品への二重登録を防ぐため、売却操作を表示しません。

`sale` と `monthlyCostRounding` を通常の保存・クラウド保存・バックアップで保持します。購入価格自体は追加費用で上書きしません。
